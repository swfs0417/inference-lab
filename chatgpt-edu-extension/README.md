# GPT Edu Response Timer

ChatGPT Edu 웹 UI에서 사용자가 프롬프트를 전송한 시점부터 첫 응답 표시(TTFT), 응답 완료까지의 시간을 자동 측정하는 Chrome Manifest V3 확장 프로그램입니다.

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
4. 이 `chatgpt-edu-extension` 폴더를 선택합니다.
5. `https://chatgpt.com`의 Edu 워크스페이스 탭을 새로고침합니다.
6. 확장 팝업에서 대시보드 주소와 모델 라벨을 확인합니다.

ChatGPT 우측 아래에 `EDU TIMER · READY` 배지가 나타납니다. 프롬프트를 보내면 `WAITING`, 첫 응답 후 TTFT, 완료 후 `SAVED` 순으로 변경됩니다.

## 결과 보기

확장 팝업의 **최근 실험 결과**에는 웹 대시보드의 `/api/runs` 결과가 같은 요약 스키마로 표시됩니다. API 실험과 Browser E2E 측정을 모델, 성공률, TTFT 평균/p95, 출력 TPS 기준으로 함께 비교할 수 있습니다. **웹 대시보드** 버튼을 누르면 전체 지표와 CSV/Excel 내보내기를 확인할 수 있습니다.

## 측정값의 의미

- TTFT: Enter 또는 전송 버튼 클릭부터 새 assistant 응답에 텍스트가 보일 때까지
- 전체 시간: 전송부터 마지막 텍스트 변경 후 quiet window가 지난 시점까지
- 생성 시간: 첫 텍스트 표시부터 완료 판정까지
- 출력 토큰: 응답 글자 수 / 3.5의 근삿값

이 수치는 브라우저 렌더링, 네트워크, OpenAI 측 대기열을 포함하는 Browser E2E입니다. OpenAI 내부의 순수 추론시간이나 GPU 사용량이 아닙니다.

## 개인정보

확장 프로그램은 프롬프트와 답변 텍스트를 저장하거나 전송하지 않습니다. 시간, 응답 글자 수, 추정 토큰 수, 페이지 호스트, 사용자가 입력한 모델 라벨만 대시보드로 보냅니다.

## 주의

ChatGPT 웹 UI의 DOM 구조가 변경되면 측정이 멈출 수 있습니다. 배지가 `WAITING`에서 진행되지 않으면 개발자 도구로 assistant 메시지와 정지 버튼 선택자를 확인해 `content.js`를 갱신해야 합니다. 도구 호출, 웹 검색, 이미지 생성은 일반 텍스트 응답보다 완료 판정이 부정확할 수 있습니다.
